TNB Electricity Meter Monitoring App
An automated web-based application designed to monitor electricity consumption, manage meter readings, track utility bills, and send automated notifications for the Tenaga Nasional Berhad (TNB) billing system.

Page Features
index.php: The landing or welcome page that introduces the application and directs users to authentication or the main dashboard.

login.php: Handles user authentication and login sessions.

logout.php: Terminates the current user session and redirects back to the login page.

dashboard.php: The central control hub displaying system overviews, quick statistics, recent meter readings, and consumption charts.

meters.php: Manages electricity meter registries, including adding, updating, or assigning meters to specific properties and users.

readings.php: Displays the historical list and logs of all submitted electricity meter readings.

submit_reading.php: Allows users to input new meter readings, complete with camera capture support for photo verification of the meter status.

users.php: Manages user accounts, roles, and administrative controls within the system.

settings.php: Configures application-wide settings, notification preferences, and system parameters.

setup_create_accounts.php: Initial setup script used to seed or generate default administrator and user accounts in the database.
